# 个人工作台 Demo

版本：demo-0.1.0。基线：[产品方案 0.1-draft 修订 3](../product/outline.md)。2026-09-16 用户选择第 3 张方向稿，现已实现本地可交互前端，用于对齐布局和主要操作；正式 DSH 桌面应用仍待方案与 Demo 确认。

## 最新方案差异

方案已更新至修订 5：[首页功能定义](../product/features/workbench.md)。新版采用输入框与同页平铺插件桌面，支持文件/网页快捷方式及经 Skill 开发、由定时任务更新数据的小组件；通用安装方式后置。本 Demo 仍为修订 3 的文件图标与右侧任务布局；本轮只定义功能，尚未更新代码。以下操作说明及验证记录均指现有 demo-0.1.0。

## 打开与启动

运行时入口：[个人工作台](http://127.0.0.1:4173/)。服务停止后，在此项目的 `demo/app` 目录启动：

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 4173 --strictPort
```

使用 Node.js 24，本轮实际版本为 24.19.0。依赖版本由 package-lock.json 固定。构建命令为 `npm run build`；本地生成 dist，不部署、不上传。

## 建议体验顺序

1. 首页输入任务，选择工作空间与能力，点击“开始任务”。右侧出现模拟进度和授权请求，允许后打开成果；也可停止、拒绝或重试。
2. 桌面“新建”对象，通过图标右上角管理名称、分组或置顶；拖动调整顺序。“视图”切换列表和分组，“搜索”筛选对象。示例文件可预览和导出 Markdown。
3. 能力广场按 Skill、连接器和 Subagent 筛选，启停能力，打开配置并执行“演示检查”。
4. Harness 设置选择模块，编辑上下文策略；“改进执行方式”填写反馈、查看示例 A/B、应用建议，再从配置版本恢复旧版本。
5. 知识库导入示例资料，审阅候选 Wiki，确认后进入图谱，点击节点追溯来源；撤销来源后相关知识和关系退出可用范围。
6. 协同创建任务草稿，指定对象与共享材料，保存后状态为“未发送”。
7. 左下角切换本地演示账号，观察桌面和知识变化。右上角“对齐说明”显示功能 ID，并直接读取产品 Markdown 文档；“重置演示”恢复初始数据。

## 演示范围

任务执行、连接检查、Wiki 生成与 A/B 指标使用固定样例，没有连接 DSH、模型、真实目录或外部服务。会话只保留每个演示账号最近一次任务，不实现生产级会话历史；刷新时未完成任务标为中断，不自动重放。文件夹仅组织示例对象，不提供真实目录浏览。

交互状态存于本浏览器 localStorage；账号切换展示归属体验，不证明安全隔离。清除站点数据会丢失演示修改。协同仅保存草稿，不发送。产品完整规则以[方案](../product/outline.md)为准；各链路通过[对应表](../product/demo-map.md)关联正式工程验收。
