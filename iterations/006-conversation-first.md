# 006 · 功能分区与对话优先

日期：2026-09-20。状态：规划文档完成，详细范围与 P1 Demo 待对齐；正式工程未启动。

## 目标

按用户要求，把全部规划功能分区管理，前期先专注对话，后续分期实现。保留完整产品方向，将首版验收收敛到可用的对话闭环。

## 变更

建立[功能清单](../product/features.md)，沿用已有 ID 并拆出跨阶段子项，统一阶段、状态与完成条件。产品方案升级为修订 6；首页、账号、页面行为、Demo 对应关系和工程实施顺序同步。旧稿五模块都在 v0.1 完成、协同 v0.2 的建议不再生效。

P1 建议覆盖安装包、首个本地账号、模型设置、输入与历史、资料引用、工具状态、审批提问停止、成果查看与恢复。后续按桌面与能力、小组件、知识、Harness、协同安排。所有正式功能仍未开发；本轮未改 Demo 源码、未接入 DSH、未运行模型或创建真实调度。

## 下一步与验收

先对齐 P1 的详细交互并更新 Demo，通过后记录该阶段正式开发范围。工程首步验证包内真实 DSH 对话与人工控制，再补历史、成果和安装包恢复验证；P2 以后不作为 P1 验收前置条件。
