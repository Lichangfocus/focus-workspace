## 真实模型改进样例

使用用户已配置模型，实际 request model ID 为 `deepseek-v4-pro`（模型目录已说明兼容路由），只使用专门的无执行工具验收模式和非敏感算术题。

1. 基准输入“请回答：2+2 等于多少？”，模型回复“2+2 等于 4。”。
2. 记录反馈“只输出结果数字”，点击生成改进任务。Agent 真实返回完整配置，将附加指令改为“回答算术问题时，只输出结果数字，不添加解释、单位或任何其他文字。”。
3. 导入候选并打开独立试跑会话，输入同一问题，实际回复“4”。
4. 记录对照结果，采用到草稿；比较仅 `instructions` 有变化，发布 v2。
5. 观测基准会话仍对应 v1，实际模型显示 `deepseek-v4-pro`，0 个工具结果、19 个事件、completed。账号默认始终保持标准模式。
6. 从桌面恢复到 v1，保留 v2、反馈、候选和采用记录；最后归档“验收 · 简洁回答”模式，保留可查验的会话。

这验证了受控改进链路和一个输出格式目标，不证明复杂任务能力整体改善，不属于自动进化效果评测。
