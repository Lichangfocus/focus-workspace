## 交付

独立 React + Vite 前端位于 demo/app；覆盖首页、能力广场、Harness、知识库、协同和本地演示账号。完整方案仍在 product/，Demo 的对齐说明直接导入这些 Markdown 文件。功能 ID 与正式工程区别见[对应表](../product/demo-map.md)。

正式工程目录仍为占位，没有 DSH、模型、真实连接器或跨人通信接入。本轮未创建远端或推送 GitHub。

## 实际验证

- `npm run build`：通过，生产 JS 约 429 KB（gzip 127 KB）；只生成本地产物。
- 内置浏览器：发起任务、允许授权、生成成果与文档预览；停止、重试、拒绝均验证。
- 桌面：新建学习分组对象、列表视图、关键词搜索；方案说明能打开完整产品文档。
- 能力广场：连接器筛选、笔记空间启用、配置演示检查与保存。
- Harness：反馈、示例 A/B、应用 v2、恢复 v1；模块配置来源可查看。
- 知识：示例资料导入、候选审阅、图谱追溯；撤销来源后图谱关系从 2 条降为 1 条。
- 协同：选择对象和共享材料、保存并预览“未发送”草稿。
- 账号：切换空账号再返回，数据分别展示；刷新后新增成果仍在。
- 布局：1487×1058 与方向稿同尺寸比较；1280×800、820×900 检查，修复主内容溢出导致账号入口不可见的问题。
- 浏览器控制台：本轮检查未发现 error 或 warn。重置演示恢复初始数据。

不声称验证了真实 DSH 行为或数据安全隔离。拖拽排序、Markdown 下载和新增能力/新增账号表单已实现，但本轮未逐项做端到端验证。正式工程验收独立安排。
