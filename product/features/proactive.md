# 主动性 AI

> 所属：[产品大纲](../outline.md) · 支柱三「主动性 AI」 · 功能 ID：PROACTIVE-01、PROACTIVE-02、PROACTIVE-03，并承接 HOME-06、HOME-07.1、HOME-07.2 · 阶段 P3 起 · 阶段与状态以[大纲功能清单](../outline.md#七功能清单)为准。

状态：待细化。本页只记录定位、范围和已知约束，具体交互在进入 P3 前对齐。

## 目标

Agent 不只等待指令：按计划、事件或对工作记录的观察，主动执行任务、提醒用户、提出建议。主动性建立在 P1 的模式版本、审批和执行证据之上，主动产生的每个动作都能追溯到触发原因。

## 功能范围

| ID | 功能 | 说明 |
| --- | --- | --- |
| HOME-06、HOME-07.x | 定时任务驱动的工作台小组件 | 已有详细设计，见[工作台](workbench.md#定时任务与数据渲染home-07) |
| PROACTIVE-01 | 定时与事件触发任务 | 按时间、文件变化、外部消息等触发一次模式化任务；优先复用 DSH 的 schedule、jobs、webhook 插件 |
| PROACTIVE-02 | 主动建议 | 从任务记录中发现重复纠正、反复临时追加的能力、未完成的行动项，向用户提出建议；与 EVOLVE-05 共用证据，不自动修改配置 |
| PROACTIVE-03 | 主动结果收件箱 | 所有主动产生的结果、提醒和建议有统一接收处，可接受、忽略或转为任务 |

## 已知约束

- 固定版 DSH 的 schedule 为持久化会话提醒：冷会话不执行，重复间隔至少 300 秒，没有日历重复规则（见[上游接入记录](../../engineering/upstream.md#界面与接入证据)）。
- 电脑退出或休眠时不承诺执行；错过的执行显示为漏跑，不静默补跑有副作用的任务。
- 主动任务不扩大权限，外部动作沿用正常审批；无人值守执行需要单独授权。
