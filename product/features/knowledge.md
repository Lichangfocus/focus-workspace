# 知识库

> 所属：[产品大纲](../outline.md) · 支柱五「构建自身的知识库」· 功能 ID：KNOW-01.1、KNOW-01.2、KNOW-02.1、KNOW-02.2、KNOW-03 · 阶段 P4 · 状态以[大纲功能清单](../outline.md#七功能清单)为准。

## 完整行为（待对齐）

提供来源、Wiki、图谱三个视图，可限定工作空间或账号通用范围。首期支持 UTF-8 Markdown/纯文本工作空间资料及本产品会话；其他类型显示不支持，不静默跳过。

导入显示来源列表、读取范围、进度和失败项。用户预览后授权；默认不递归导入隐藏目录、依赖产物和凭证文件。目录导入建立受控来源引用及快照，整理器不改写原文件。

生成内容先进入待审阅区，显示建议、原文片段和变更，确认后进入可检索 Wiki。实体、关系关联证据，同名实体可合并，错误关系可删除。重新生成采用差异审阅，保留手工编辑和历史版本。

来源变化后显示“待更新”；移除或撤销权限后，相关派生知识立即停止向新任务提供，并标记受影响的 Wiki。历史任务引用保留审计记录，彻底删除敏感内容须显式清理历史与备份。

Agent 查询返回摘要、来源定位及版本，必要时再读原文，不把整个知识库一次性加入上下文。检索必须经过账号及工作空间范围过滤。
