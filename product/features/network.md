## 目标

让用户自己的 Agent 能与其他人的 Agent 在授权范围内交流、委派任务和回传结果（交友），并能把自己验证过的模式、Skill 分享到 DSH 生态、从生态中获得他人的能力（成长）。两者都建立在 P1 的模式版本、账号归属和权限基础上。

## Agent 协同（COLLAB）

协同阶段先提供自己的 Agent 名片，创建协作对象记录和任务草稿。名片说明职责及可接受任务，不能包含凭证或默认共享整个知识库；联系人记录不等于已连接的真实对方。

通信功能的流程为：确认对方身份与能力 → 选择任务和共享材料 → 审阅并发送 → 对方接收或拒绝 → 跟踪状态 → 接收带来源的结果。发送、重试、超时与取消都有记录，重复消息不能触发重复执行。

对方内容按外部输入处理，无权直接读取本地文件、调用连接器或修改 Harness。接受任务后只在该次协作授权范围内执行；断网时显示真实状态，不伪造已送达或已完成。

## 生态分享（NET-01，待细化）

- 把一个已发布的模式版本或 Skill 导出为可分享包（脱敏，不含凭证与账号数据），可发布为带 `dsh-plugin` topic 的 GitHub 仓库或 npm 包。
- 从生态安装他人分享的模式/Skill 时，先展示来源、权限需求和差异，安装为新的用户模式或能力资产，不覆盖已有配置。
- 与 HARNESS-04.4 的导入导出共用格式；在线市场与付费（MARKET-01）后置。
